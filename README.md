# «Ты в порядке, Саня?» — демо-лендинг

Демо-проект для портфолио: лендинг частной многопрофильной клиники. Клиника вымышленная, врачи, цены и отзывы придуманы, заявки никуда не отправляются.

## Моушн-графика

- Первый экран — чат с клиникой: «Саня, ты в порядке?». Бот «печатает», посетитель отвечает кнопками, ветки диалога заканчиваются подходящим врачом или чекапом и кнопкой записи
- Знак вопроса в заголовке покачивается, наклейки с пульсом и давлением плавают вокруг чата, сердечко бьётся
- Наклонная бегущая строка направлений с кардиограммой
- «Как проходит чекап»: кардиограмма рисуется при прокрутке, каждый удар — шаг утра, часы идут с 08:30 до 11:00, последний штрих превращается в галочку «Саня в порядке»
- Нарисованные в SVG врачи моргают и наклоняют голову при наведении
- Счётчики цифр, аккордеон вопросов, пульсирующая точка на схеме проезда
- Всё уважает `prefers-reduced-motion`: прокручиваемая кардиограмма превращается в обычный список шагов

## Функциональность

- Любая кнопка «Записаться» (в чате, в карточках врачей, направлений и чекапов) подставляет услугу в форму и прокручивает к ней
- Форма записи: направление, дата на 7 дней вперёд, свободные и занятые слоты (в выходные — до 18:00), имя, телефон с маской, согласие; валидация и экран «записали»
- Обязательное для медицинской рекламы предупреждение «Имеются противопоказания» в подвале
- Иллюстрации, иконки и схема проезда — SVG, без сторонних картинок

## Стек

React 19, TypeScript, Tailwind CSS 4, Motion, Vite.

## Запуск

```bash
npm install
npm run dev
```

Сборка в `dist/`: `npm run build`. Пути относительные — сборку можно выложить в любую папку, например на GitHub Pages.
